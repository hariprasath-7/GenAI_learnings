# Phase 3 — Embeddings & Vector Search
## Quick Notes — Lessons 13–19

### 13. Vector Index
- **Definition:** A data structure used to search vectors faster instead of checking every vector one by one.
- **Example:** A vector index helps find the most similar product embedding quickly.

### 14. ANN (Approximate Nearest Neighbor)
- **Definition:** A search approach that finds very similar vectors quickly without checking every vector.
- **Example:** Search 10 million product vectors by checking only promising candidates instead of all 10 million.

### 15. HNSW
- **Definition:** A graph-based ANN algorithm that uses multiple layers to navigate to nearby vectors quickly.
- **Example:** Start from a higher layer, move toward a promising vector, then go to lower layers for a more detailed search.
- **Memory:** `HNSW = Graph + Layers + Fast Navigation`

### 16. FAISS
- **Definition:** A similarity-search library used to search and find nearest vectors efficiently.
- **Example:** Convert `"cheap phone"` into a vector and use FAISS to find the closest product vectors.
- **Memory:** `Embedding Model → creates vectors | FAISS → searches vectors`

### 17. Embedding Model
- **Definition:** A machine-learning model that converts text or other data into numerical vectors representing meaning.
- **Example:** `"I love Python"` → Embedding Model → `[0.21, -0.73, 0.44, ...]`

### 18. Choosing an Embedding Model
- **Definition:** Selecting an embedding model based on the requirements of your application.
- **Important factors:** Quality, dimensions, speed/latency, cost, language, context length, and domain.
- **Example:** For a multilingual RAG system, choose a model that performs well for all required languages.

### 19. Open-Source vs API Embeddings
- **API Embedding — Definition:** An embedding model hosted by a provider and accessed through an API.
- **Example:** `App → Embedding API → Vector`
- **Open-Source/Self-Hosted — Definition:** An embedding model that you run and manage on your own infrastructure.
- **Example:** `App → Local Embedding Model → Vector`
- **Memory:** `API = Easy + Provider Managed | Self-Hosted = Control + You Manage`
