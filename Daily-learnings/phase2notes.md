# Phase 2 — Prompt Engineering: Completed Notes

**Verified progress: Lessons 1–20 complete.**

The old record preserves the following completed topics. Lesson 18 was completed, but its title was not preserved, so it is intentionally not guessed.

1. **Prompt Basics** — A prompt tells an AI what to do. Clear instructions usually give better results.
2. **Zero-Shot Prompting** — Ask the model to do a task without giving examples.
3. **One-Shot Prompting** — Give one example to show the wanted output.
4. **Few-Shot Prompting** — Give a few examples so the model can follow the pattern.
5. **Role Prompting** — Give the model a useful role, such as a teacher or support assistant.
6. **Context Prompting** — Give the background information the model needs to answer well.
7. **Instruction Prompting** — State the task, rules, and output clearly.
8. **Chain-of-Thought** — For difficult work, asking for step-by-step reasoning can improve results.
9. **Self-Consistency** — Use more than one reasoning path and choose the most consistent answer.
10. **Tree of Thoughts** — Explore different possible reasoning paths before choosing one.
11. **ReAct** — Combine reasoning with actions, such as deciding what information to look up.
12. **Meta Prompting** — Use prompts to help create, improve, or review other prompts.
13. **Structured Outputs** — Request a predictable structure, such as JSON, so software can use the response.
14. **Output Constraints & Formatting** — Set limits such as length, allowed values, or an exact format.
15. **Prompt Chaining** — Use the output of one prompt as input to the next step.
16. **Prompt Templates** — Reuse a prompt structure and fill in changing values.
17. **Delimiters & Context Isolation** — Clearly separate instructions from user data using markers or sections.
18. **Completed topic (title not preserved)** — Recorded as complete; do not rename this without the original roadmap.
19. **Prompt Security** — Treat user content as untrusted. Design prompts and systems to resist prompt injection.
20. **Prompt Evaluation** — Test prompts with many representative cases. Measure accuracy, relevance, consistency, format compliance, and safety; then improve and test again.

## Important memory note

Do not trust a prompt because it works once. Compare prompts on the same evaluation set and use the results to decide which is better.
